Bảng Hướng Dẫn Kiểm Thử (Sprint 13 — Strategy Pattern)

1. Kiến trúc Strategy Pattern:

Tất cả Nhà cung cấp (EVN_HN, WATER_HCM, VIETTEL_TEL) triển khai chung Interface PaymentProvider.

2. Phỏng vấn OCP (Open-Closed Principle):

Khi thêm Provider mới (ví dụ MoMo), chỉ cần tạo Class mới implement PaymentProvider với @Component. Spring IoC tự động đưa vào PaymentProviderFactory mà KHÔNG sửa 1 dòng code nào hiện tại!

3. Tích hợp Ledger sổ kép & Outbox:

Mỗi giao dịch thanh toán tự động ghi Bút toán Sổ kép Double-Entry trừ tiền tài khoản và phát bản tin PAYMENT_COMPLETED sang Outbox Pattern.
